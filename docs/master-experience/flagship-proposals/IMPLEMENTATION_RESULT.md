## Local security and accessibility

All app state is memory-only. There is no fetch, API client, browser storage, socket, telemetry, hosted Auth, payment or messaging adapter. Inputs use bounded lengths and HTML escaping. Private draft values never populate share previews. Consent is tied to the selected sample relationship and channel. Native modal behavior provides focus containment, Escape and return focus. Keyboard reorder uses up/down alternatives and keeps focus on a valid movement control. Invalid empty feedback focuses its field and associates the error. Layout supports reduced motion, forced colors, text resizing and responsive mobile navigation. Rendered acceptance belongs to the independent review, not these source claims.

The preview launcher serves a pre-read immutable byte snapshot of allowlisted integrity-checked files on 127.0.0.1 with Host validation, no other methods, no cache, no referrer and CSP connect/form/frame/object denial. It does not invoke a browser, install dependencies, create remote resources or read credentials. The owner-friendly `.command` launcher only starts that reviewed Node script.
