# Connected discipleship boundaries

This package extends the existing local synthetic member composition. It does not replace the original course engine, player transport, autosave, watch-credit or completion rules.

## Data and authority

- Owner, lesson and revision delimit each memory-only learning store. Dispose/reset, public-recipient and identity/read-mode transitions invalidate private state.
- Display percentages, answer counts and local continuation are presentation only. Neither 95% nor 100% simulated progress grants completion, verified watch credit, enrollment or protected-resource access.
- No real member identities, passwords, session material, protected download URLs or provider calls are used.
- The unchanged course-engine questionKey and worksheetState helpers are reused through a single exact-path/hash exception. Other server files and effectful imports remain denied.
- Synthetic teaching questions are review fixtures, not approved Salvation, Kingdom, King Kind or in-Christ curriculum. Pathway taxonomy is preserved while rights/content availability remains explicit.
- Actual playback, caption tracks, autosave and protected downloads remain disconnected. Lessons 11–13 remain Media Coming Soon.

## Design

Desktop keeps media left, worksheet right, with a sticky/minimizable media area. Mobile stacks the same content. Existing dark member shell and approved color direction are retained; no new logo, photo or premium-screen approval is inferred.

## Release

All work stays in separate local branches/worktrees. No production/provider action, managed database connection, hosted Auth, user creation, migration, sending, payment, reservation, deployment, push or merge. The 40-file deployment operator remains untouched; diagnostic allowance CONSUMED and application reservation UNUSED.
