## Verified local identity, authorization and response behavior

`netlify/lib/member-read-server.mjs:11-16` checks expected isolated issuer/ref, authenticated audience/role, UUID subject/session, expiry and AAL as a prefilter. It does not treat unverified token parsing as successful authentication. The fixed isolated provider `/auth/v1/user` must return the same subject and not an anonymous user (`:67-70`). The caller bearer and project publishable key are reused for the stable active-session RPC before and after the data reads (`:71-94`). No refresh or Set-Cookie occurs in this factory. Existing `requireSession` can refresh (`lockliel-core.mjs:62-73`), so using it unchanged would violate the strict read-factory lifecycle. Login/session lifecycle is a separate future authorization, not a domain read.

Only owner-filtered `profiles` and `communication_preferences` requests are issued, with fixed selected columns and limit=1 (`member-read-server.mjs:77-91`). Projection rejects foreign-owner/multiple/malformed rows (`member-read-projection.mjs:4-30`) and never spreads provider records. The selected profile is id/name/onboarding; preferences are owner ID, five booleans and updated_at (`:32-33`). Wire data contains display name/initials/assurance, own onboarding and five flags with timestamp revision. User IDs, email/phone, inviter/campaign/leader joins, roles, notes/prayers/growth, financial/assessment data, entitlements and Storage paths are not emitted. Staff metadata does not broaden the owner filter. AAL is a displayed assurance, not a staff grant.

Missing rows remain `missing`, per-domain upstream errors remain `unavailable`, and 401/403 terminate the read. Generic identity label Member on a missing profile is explicit fallback presentation, not a fabricated saved profile. Dashboard courseAvailability is always unavailable (`member-read-server.mjs:95-100`); this package has **no real course dashboard summary**. Tests and reports must not describe unavailable course data as a connected progress read or claim that all dashboard domains are integrated.

Errors are generic; private/no-store, both CDN no-store, Vary Cookie and no-referrer headers apply (`member-read-server.mjs:7-9,101-104`). Upstream response bodies have a 64 KiB streaming limit and transport deadlines; the browser rejects invalid content type, over-limit body or malformed DTO. `adapter.ts:15` checks client length after response.text completes, so server response size and deployment HTTP limits remain relevant defense-in-depth, not an unbounded-input guarantee on arbitrary malicious origins. No production endpoint fallback or mock fallback exists.
